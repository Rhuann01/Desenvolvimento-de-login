## Login com validação propria
Eu criei esse login com intuito de aprender mais sobre como fuciona a criação e validação de login por trás, para melhor apredizajem eu me limitei a não usar libs que facilitariam esse processo, como authur.js entre outros, eu utilizei next.js com ts, esse login contem coisas como validação de campos, criação e verficação de token, utilização de ORM prisma. Eu apliquei os metodos de proxy do next.js que utilizei para validar se o usuario tem ou não um token criado (gerado ao fazer login), senão tiver e tentar entrar em uma area provada do site, ele redericiona pra login, que está como uma areá publica. obs: além da validação no front existe a validação no back end, par evitar dados enseridos pelo postmen ou iguais, enviem dados despadronizados.
